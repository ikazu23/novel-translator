# 韓国小説 丸ごと翻訳

**韓国語・中国語・英語**の小説を、ページを開いたまま自然な日本語で読めるスクリプトです。
話全体の流れを見て訳すので、呼び方や口調がそろいます。太字・色・空行などの見た目もそのままです。

## 入れ方

1. ブラウザに拡張機能の **Tampermonkey** を入れる
   - Android：Firefox か Edge
   - iPhone / iPad：Safari（App Storeの Tampermonkey・有料）
   - PC：Chrome か Edge か Firefox
2. 下のリンクを開いて「インストール」を押す

👉 **[スクリプトをインストール](https://raw.githubusercontent.com/ikazu23/novel-translator/main/korean-novel-translator.user.js)**

> 拡張機能が使えないブラウザでは使えません。
> インストール画面が出ないときは、Tampermonkeyの「ユーティリティ」→「URLからインストール」に上のリンクのアドレスを貼ってください。
> iPhone / iPadは、Safariの設定でTampermonkeyを「すべてのWebサイト」で許可してください。

## 準備（APIキー）

翻訳には **Gemini** のAPIキーを使います（安い・速い）。

1. [Google AI Studio](https://aistudio.google.com/) でAPIキーを作る
2. 支払い（課金）を設定する

小説のページで右下の **⚙** を押し、APIキーを貼って **保存**。

## 使い方

| ボタン | 動き |
|---|---|
| **訳** | 翻訳する |
| **原** | 原文に戻す |
| **写** | 訳文をコピー |
| **保** | この話をHTMLで保存 |
| **⚙** | 設定 |

- 原文の言語（韓国語・中国語・英語）は自動で判定します
- 一度訳した話は保存されるので、開き直しても料金はかかりません
- ほかの機能（作品ごとにまとめて保存・バックアップなど）は、Tampermonkeyのメニューから使えます

## 料金の目安

1話 **数円くらい**。設定の「1回に送る文字数」を **10000**、「冒頭を先に表示する」を **オフ** にすると安くなります。

## 注意

- 保存したファイルは **自分で読む用** にしてください
- APIキーは人に教えないでください
- うまく動かないときは、Tampermonkeyのメニューの「診断」をスクショして作者に送ってください
